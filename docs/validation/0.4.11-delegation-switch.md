Checked on Apple Silicon on 2026-10-11. This validates optional delegation; it does not compare Opus judgment, task speed or total cost.

- 189 gateway tests and 24 release/native-settings tests passed (213 total).
- Native Swift release build passed, including the new Settings control.
- Legacy configuration migration retains enabled delegation; disabling and re-enabling survive configuration round trips, with provider/vision/memory settings preserved.
- Packaged MCP initialization reported `0.4.11`, protocol `2025-11-25`, and 29 tools with saved delegation enabled.
- Read-only DMG verification passed bundled runtime imports and ad-hoc signature checks. Not notarized.

| Mode | Tools exposed | Verified fixture read | Delegated call behavior |
| --- | --- | --- | --- |
| Off | 26 | Direct extraction succeeded | Executor call blocked |
| On | 29 | Executor extraction succeeded in one browser dispatch, with no decision inference | Saving off in the same connection blocked a cached executor call |

The harness now handles the documented compact result forms and uses controlled fixture DOM. Those setup failures do not establish a model quality or speed difference; they are not omitted successes from an Opus benchmark. Identified temporary tabs were closed.
