## Live trials

Two six-attempt workloads on the owned BrowserOS Neo canvas fixture, isolated temporary gateway state and memory disabled. The installed native helper supplied the existing TypeSafe key through captured private IPC. Neither trial changed saved settings or production memory. The first described entire colored tiles; the second used precise white-shape descriptions. Pinned `jev-1.14.0`, target-probability and box-confidence threshold both 0.9. No retries or fallback, one System One request per attempt.

| Trial | Accepted visible target points | Correct absent/ambiguous refusals | Visible target refusals (including click) | Verified clicks |
| --- | --- | --- | --- | --- |
| Whole-tile descriptions | 1/3 | 2/2 | 3/4 | 0/1 |
| White-shape descriptions | 0/3 | 2/2 | 4/4 | 0/1 |

The accepted circle point landed inside its independently observed fixture tile. Both attempted clicks stopped before dispatch. The final outcome text remained `Waiting for a selection`, independently observed through Neo. The overall live smoke checks failed because intended visible targets were refused; all attempts remain in the JSON reports. This demonstrates working API/transport and conservative refusal behavior, not successful general UI grounding or task completion. It does not establish that 0.9 is an appropriate production threshold.

Across 12 API calls: 36,189 reported input tokens; median provider inference 0.134s. Input-rate cost estimate: $0.00151994, using the published $0.042/M rate and free output. These are provider latency and a rate-based estimate, not end-to-end task speed, measured billing or total task cost. No main-agent/local/OpenRouter comparison was performed. Missing main-agent cost and memory costs are not inferred as zero.

Retained raw reports (local ignored artifacts): `dist/jev-vision-smoke-0.5.2-initial.json` and `dist/jev-vision-smoke-0.5.2-shapes.json`. Reproduce using `python3 -B script/jev_vision_smoke.py --report dist/jev-vision-trial.json`, optionally adding `--shape-targets`; this reads the saved TypeSafe key and incurs API charges on synthetic fixture screenshots only.

## Operational decision

Ship as an explicitly selected experimental provider; preserve the current saved OpenRouter selection and local defaults. Do not automatically route real tasks to Jev image grounding. Keep existing pixel/layout freshness, cancellation, single-click and postcondition checks. Tune on a representative independently labeled workload before selecting it for routine work. No 10x speed or lower total cost claim is supported.
