# 0.4.10 delegated executor validation

Checked on an Apple Silicon Mac on 2026-10-11. This validates mechanisms and packaging; it is not a matched Claude/Codex end-to-end benchmark.

## Automated checks

- 183 gateway tests passed using bundled Python 3.12, with no skips.
- 24 script, release and native-settings tests passed.
- Swift release build passed.
- Packaged MCP negotiated protocol `2025-11-25`, reported version `0.4.10` and exposed 29 tools including `openragnar_execute`.
- DMG mounted read-only; bundled imports and ad-hoc signature checks passed. Developer ID signing and notarization remain pending.

Executor regressions cover permission/schema rejection before browser dispatch, guarded missing-element extraction, cancellation and budgets, provider errors/uncertainty, stale navigation, incomplete completion evidence, point-only vision, verified-route reuse and failed-route invalidation.

## Live browser mechanisms

`neo-personal/live_executor.py` ran alternating warm reads on an owned static fixture, with memory disabled and no paid inference. Both paths checked the same heading and reported the same missing optional field.

| Path | Runs | Successful checks | Browser dispatches | Median elapsed |
| --- | --- | --- | --- | --- |
| Two individual Neo reads | 6 | 6 | 2 | 1.886 ms |
| Batched executor read | 6 | 6 | 1 | 1.067 ms |

These very short timings include no main-agent planning and do not represent typical browser-task latency. Neo can batch reads directly too. Missing required selectors correctly escalated. A separate owned-tab check changed a heading between repeated observations; the second read returned the changed text.

Public TypeSafe documentation navigation plus inspection/extraction passed its text and heading checks with five browser dispatches in 1.063 seconds. The link choice used a deterministic fixture selector, not Jev inference. It therefore validates the navigation loop, not model decision quality or API savings.

## Installed app and provider check

The app was installed at `/Applications/OpenRagnar.app`; settings were preserved and its signature verified. Claude Desktop reconnected with two recorded connections reporting `0.4.10`.

The first installed Jev executor attempt escalated after 20.958 seconds and two browser calls because macOS denied access to the saved provider key. No decision was produced. This failed attempt is retained in the task ledger and ignored `dist/executor-installed-check.json`. A successful live Jev executor test remains pending Keychain approval.

## Remaining performance evidence

No Claude/Codex task latency, host tokens, subscription allowance impact, paid vision comparison or total-task cost was measured here. Memory embedding/storage costs remain unknown. General 10× speed and equal-or-lower total cost remain development targets.
