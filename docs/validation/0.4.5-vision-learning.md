Times include the entire tool request and are warm/possibly cached fixture measurements.

A deliberately changed test click handler then caused one reused click to fail verification. That failure revoked reuse; the next two successful attempts used the model, and the following attempt reused local evidence again. Across 14 attempts, 13 met their text postcondition and one deliberately failed it. Five local model calls were avoided; four of those reuse attempts were verified.

Earlier failed trials remain in ignored `dist/run-observations/`. They revealed that text rasterization can differ across captures and that the model can decline a target. A full-scene byte change conservatively misses coordinate reuse. The deterministic repeat trial used an empty pre-action outcome area to avoid unrelated mutable status text in its exact scene key. Click freshness still checks exact target pixels plus DOM/viewport state; its local decoder rejects unsupported or malformed PNGs. This is a controlled test, not broad GUI accuracy or speed evidence.

Regression coverage verifies scene/task/postcondition/provider/account isolation, persistence, expiry/corruption, point-only exclusion, disabling/unavailable memory, already-present text, target-pixel changes, and revocation after failed reuse. Reused successes never become independent model evidence. Native compilation includes the visual learning counters on the Experience memory page.

No 10×, Claude quota reduction, model-weight learning or improvement on every new task is established. The demonstrated improvement is avoiding inference on repeated, locally verified, identical tasks and scenes. OpenViking stores outcomes; the local execution policy decides reuse.

Reproduce with `python3 script/vision_learning.py --remote --report dist/vision-learning.json`. The `--remote` flag writes one explicitly marked validation record. Full local reports include failures and timings without screenshot data.
