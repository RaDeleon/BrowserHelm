# OpenRagnar 0.4.4 preview

- Original slate and bronze app icon: a browser gateway connecting two nodes around an angular R. Native icon sizes are included in every staged app and DMG.
- Optional local screenshot grounding through Ollama or LM Studio. The new `openragnar_visual_act` MCP tool proposes a point or performs one requested click, rechecking the viewport/layout before acting. Optional expected text verifies text presence after the click.
- Separate vision settings and a server/model availability test. Existing decision-provider and memory settings remain intact. The default local model is Qwen3-VL 2B; download it separately with Ollama. BrowserVLM's announced code/weights remain unavailable and are not included.
- Screenshots remain inside the gateway/local model connection and are not returned to the main client. Local inference usage and latency appear in the tool report; inference tokens enter the existing provider-token counters. No automatic retries, cloud fallback, coordinate memory replay or model weight training.

Apple Silicon, macOS 14+. BrowserOS Neo and your local model server must be running. Local vision is optional and off by default for fresh installs. This preview is ad-hoc signed and unnotarized until Apple Developer enrollment is approved. An updated ad-hoc build may request Keychain approval again. No 10× speed or Claude subscription savings claim is made.
