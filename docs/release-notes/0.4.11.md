# OpenRagnar 0.4.11

- Adds **Settings → Browser execution → Delegate routine browser steps**.
- Turning delegation off hides `openragnar_execute`, `openragnar_navigate` and `openragnar_visual_act`, and rejects cached calls before starting an action. Direct browser tools, compact results and task tracking remain available.
- Saved opt-out applies to new delegated requests in existing clients; reconnect to refresh tools and instructions. Running plans finish under their original limits.
- Preserves legacy configuration, provider profiles, memory settings and credentials. Existing configurations retain enabled delegation pending matched comparisons.
- Tests verify opt-out, re-enabling, malformed-settings rejection, cached-call rejection and direct-tool forwarding.

See [comparison procedure](../benchmarks.md#delegation-onoff-comparison) and [switch validation](../validation/0.4.11-delegation-switch.md). No matched Opus High comparison has yet established a speed, quality or total-cost advantage. This remains an ad-hoc signed preview.
