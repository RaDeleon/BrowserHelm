# BrowserHelm 0.5.4

- Expired Neo transport sessions are renewed once before the next request, with a fresh initialization and negotiated protocol. The rejected request is returned as an error and never replayed. Timeouts do not trigger replay or session renewal.
- Overview shows task-linked call coverage, benchmark/provider record counts, and direct/delegated/vision/local-helper usage. Path counts exclude clients explicitly named as tests or validation; remaining calls are not guaranteed production-only. Missing cost and usage remain unknown.
- Validation-mode direct outcomes retain a test label and cannot populate production failure signatures. Navigation outcomes honor validation mode. Older memory records retain their original stored contents and display legacy provenance; older provider-labeled validation records display as validation.
- Metrics, diagnostics, task and experience database transaction contexts explicitly close SQLite connections.

No provider settings are changed. These fixes do not establish an end-to-end speedup or cost reduction. Follow `docs/benchmarks.md` for matched task comparisons.

## Included since the last GitHub release (0.5.1)

- Updated vision-provider settings and per-provider model profiles, with DeepSeek as the default when explicitly selecting OpenRouter. Existing user choices are preserved; cloud vision remains opt-in.
- Retained experimental Jev, Qwen and UI-TARS trial evidence and strengthened guidance for DOM-first execution, unique visual targets and explicit verification.
