# BrowserHelm 0.5.3

DeepSeek V4.1 Flash is the default model when explicitly selecting OpenRouter vision. The picker lists it first with measured fixture results and the ambiguity limitation; Qwen remains an experimental manual option. Gemini is removed from the curated presets after the user declined it and research found incompatible reasoning-off settings. Custom model entry remains available. Existing saved model selections and local-first defaults for new installations are preserved.

Jev decision defaults are pinned to the tested stable `jev-1.13.0` instead of a moving alias. Experimental Jev image grounding remains separate on pinned 1.14 and is not enabled by this update. Workflow guidance prioritizes DOM refs, batched deterministic reads, bounded plans when useful, unique-target vision requests, and explicit postconditions. Planning and recovery remain with the main agent.

For this installation, keep DeepSeek vision, bounded delegation, and existing verified learning enabled; task markers and compact-only catalog disabled; result budget 2,000 approximate tokens. These are conservative settings based on current evidence. No matched 0.5.3 end-to-end speed, total-cost or model-ranking improvement is claimed.
