# OpenRagnar 0.4.10

- Adds `openragnar_execute`: one bounded read-only plan for inspection, extraction, public link navigation, scrolling and optional visual point proposals.
- Batches consecutive inspections/extractions. Missing elements return explicit null/missing fields; missing required checks escalate.
- Uses the configured decision provider for observed link choices. Matching plans reuse routes after two verified successes, with live-link and completion checks retained.
- Enforces action, step, hop, dispatch/time and cancellation limits. Returns partial progress without replaying uncertain outcomes.
- MCP guidance encourages supported delegation; direct tools remain available. Provider events integrate with prompt-task tracking.
- Tests cover missing elements, stale links, provider/low-confidence failures, changed-plan isolation and learned-route invalidation.

See [executor scope](../delegated-executor.md) and [validation evidence](../validation/0.4.10-executor.md). General 10× speed/cost benefits remain unproven. This is an ad-hoc signed preview; Developer ID/notarization remains pending.
