# OpenRagnar 0.4.7

- Delegated navigation rechecks the current page and selected live link, then follows it in the same browser call. One-link tasks use four gateway-to-Neo calls instead of five, with separate final text verification.
- Readiness waits resolve on either the requested text or a visible non-download link. Linkless pages with the answer no longer wait eight seconds for an anchor. Delayed content uses a bounded DOM observer that cleans up on completion or timeout.
- Provider keys and advisory memory are loaded only when a current observed choice needs inference. Already-satisfied tasks and verified route reuse avoid that work. Cancellation is checked before opening a tab and after recall/key access.
- Failed browser dispatches count as attempted calls. Navigation elapsed time includes synchronous outcome storage.
- 172 local tests pass, including page-side readiness tests. Live validation covers normal navigation, learned reuse, delayed text, linkless completion and rejection of a removed link. See the optimization review for the measured workload and limitations.

Apple Developer signing/notarization remains pending. This is an ad-hoc signed local build.
