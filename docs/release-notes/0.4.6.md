# OpenRagnar 0.4.6

- Settings → Vision supports local Ollama, LM Studio and cloud OpenRouter. Local selection is preserved on upgrade.
- Three researched OpenRouter presets: Qwen3.8 Flash, Gemini3.8 Flash and DeepSeek V4.1 Flash, plus a custom author/model ID.
- Save and switch models on the next request without restarting an existing MCP session. Each provider remembers its last model and endpoint.
- A shared OpenRouter Keychain credential supports vision independently of Jev. No key is put in settings or client configuration.
- Test vision authenticates and checks capabilities without screenshots or paid inference. Cloud point requests use a strict schema, 80-token limit, reasoning disabled and parameter-compatible routing.
- Fresh screenshot, target-pixel, DOM and postcondition guards also apply to cloud inference. Learning remains scoped to the selected model.
- Includes mocked cloud transport/action regressions; public model capabilities checked live. Cloud inference accuracy and latency have not yet been benchmarked.

Apple Developer signing/notarization remains pending. This is an ad-hoc signed local build.
