# BrowserHelm 0.5.2

- Adds optional experimental TypeSafe / Jev vision with pinned `jev-1.14.0`, one-request unique-target and bounding-box checks, and a tunable acceptance threshold.
- Shares the existing TypeSafe Keychain account while keeping cloud-provider credentials separate and clearing unsaved keys when switching vision providers.
- Preserves local vision defaults, saved provider selections, existing freshness checks, explicit click handling and postcondition verification.
- Includes Jev image tokens in provider accounting and scopes verified coordinate reuse to the Jev threshold and grounding policy.

TypeSafe image support is experimental. Availability testing does not send screenshots or establish grounding accuracy. No matched end-to-end performance or cost benefit has been established.
