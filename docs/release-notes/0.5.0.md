# BrowserHelm 0.5.0

OpenRagnar becomes BrowserHelm. The native app adopts Packet Studio: graphite/navy, cyan, sans-serif headings, a monitoring dashboard and the approved text-free browser/routing icon. Neo, Jev/decision providers, selected vision provider and OpenViking behavior remain supported.

The app, Swift product, Python engine, MCP server/tool catalog, build/packaging scripts and current documentation use BrowserHelm. Legacy MCP tool names, Keychain service and remote experience namespaces retain compatibility. Settings and SQLite histories migrate without overwriting existing BrowserHelm data, and client configuration migration preserves unrelated entries and permissions with private backups.

Install BrowserHelm in Applications after active tasks finish and reconnect clients. New app signatures may require Keychain approval. See the [migration guide](../browserhelm-migration.md). Historical benchmarks remain measurements of their original builds; no new speed/cost claim is made for this rename.
