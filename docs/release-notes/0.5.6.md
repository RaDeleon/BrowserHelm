# BrowserHelm 0.5.6

Claude Code now has its own connection controls, and read-only extraction avoids collecting unrelated page links that could overwhelm the executor's response limit.

- Added **Connect Claude Code** and **Remove from Claude Code** in Settings and Connectors, alongside the separate Desktop controls. Setup preserves other connectors, project settings and routing preferences. Matching configurations are left untouched; disabled or conflicting entries are not overwritten.
- Added bounded startup recovery for refused Neo connections. HTTP errors, timeouts and browser actions are never automatically replayed. Recovered startup failures remain visible in Diagnostics.
- Extraction-only plans skip unrelated links and unnecessary full-body reads. Inspection keeps 20 links, while navigation retains 60 candidates. Current-page verification is preserved.
- Restored profile/window selection and stale-binding recovery guidance in compact MCP instructions.

An identical synthetic link-heavy extraction result shrank from 111,373 to 334 bytes with the same heading and completion check. This is a mechanism test, not a 10× main-agent token or total-task cost claim. See `docs/validation/2026-11-01-routing-and-extraction-review.md` for the audit scope and limitations.

## Validation

252 engine tests and 32 script/privacy tests passed, including configuration preservation, startup recovery/no-replay, and independent extraction checks. Native release compilation, packaged MCP negotiation, and live delegation-on/off fixtures passed. The link-heavy extraction completed in one browser call without inference and matched an independent DOM read. The release installer is signature/checksum verified before publication.

Requires an Apple Silicon Mac running macOS 14+ and BrowserOS Neo. This preview is ad-hoc signed and **not notarized**; it is not a Developer ID-signed production release. Start a fresh Claude Code/Codex session or reconnect Claude Desktop after updating. A configured connector does not force the agent to select BrowserHelm.
