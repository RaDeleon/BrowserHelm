OpenRagnar is a native macOS MCP gateway connecting Claude Desktop, Codex and other MCP clients to a separately installed BrowserOS Neo.

This prerelease includes the redesigned dashboard, full browser read/write tools, configurable Jev/OpenRouter/Ollama/LM Studio providers, searchable diagnostics, and OpenViking experience memory. Locally proven public navigation routes can avoid repeated provider decisions; direct browser requests record safe failure/recovery lessons. Concurrent metrics readers and writers now use SQLite WAL mode.

**Download:** `OpenRagnar-0.4.3-arm64.dmg` for Apple Silicon Macs running macOS 14 or later. Open the image and drag OpenRagnar into Applications. BrowserOS Neo must be installed and running separately. Connect Claude Desktop from OpenRagnar's Connectors page, then restart the client.

**Signing:** this experimental build is ad-hoc signed and is **not Apple-notarized**. macOS may require approval through System Settings → Privacy & Security. Keychain may request approval after an update. Developer ID signing and notarization are pending Apple Developer enrollment.

The attached SHA-256 file checks download integrity. The verification JSON reports the automated DMG/runtime checks. Release CI runs offline tests and packaging checks; it does not access your browser accounts or call paid decision providers.

Text savings are byte-based estimates. This release does not claim measured Claude quota savings or a demonstrated 10× end-to-end speedup. Memory improves retrieval and reuse, not model weights, and never automatically replays browser writes.
