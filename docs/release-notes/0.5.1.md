# BrowserHelm 0.5.1

The first BrowserHelm preview replaces OpenRagnar with the new app name, browser/routing icon, graphite/navy surfaces and cyan accents. MCP helpers use `browserhelm_` names; cached legacy tool calls and existing Keychain/OpenViking namespaces remain compatible. Migration preserves settings, diagnostics, usage history and experience memory.

Settings and Connectors now offer **Remove from Claude Desktop** and **Remove from Codex** beside their connection buttons. A confirmation explains that running sessions retain their tools until the client restarts.

Removal deletes only this app's matching browserhelm MCP entry, preserves unrelated settings/connectors, makes a private backup and refuses malformed configurations, symlinks, conflicting launchers or concurrent edits. Codex removal also handles the entry's nested tool settings without rewriting other TOML tables. App settings, saved keys, history and memory are retained. Removing an absent entry is a no-op; connection controls can add it again.

Source/download safeguards now exclude generated reports, logs, captures, databases, private configuration and local agent state. Commit and app packaging checks reject recognized private/test artifacts. Reproducible test source and sanitized benchmark summaries remain available.

Requires an Apple Silicon Mac running macOS 14+ and a separately installed BrowserOS Neo. This preview is ad-hoc signed, not notarized. General 10× task speed and total-cost savings remain development targets.
