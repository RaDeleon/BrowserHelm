# BrowserHelm 0.5.1

Settings and Connectors now offer **Remove from Claude Desktop** and **Remove from Codex** beside their connection buttons. A confirmation explains that running sessions retain their tools until the client restarts.

Removal deletes only this app's matching browserhelm MCP entry, preserves unrelated settings/connectors, makes a private backup and refuses malformed configurations, symlinks, conflicting launchers or concurrent edits. Codex removal also handles the entry's nested tool settings without rewriting other TOML tables. App settings, saved keys, history and memory are retained. Removing an absent entry is a no-op; connection controls can add it again.
